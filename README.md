A personal pregnancy tracker lives in the `bump/` folder: https://kzurm.github.io/github.io/bump/

Plain HTML, CSS and JavaScript with no build step. Data stays in the browser, with optional encrypted backup to a private GitHub Gist (set up in the app's Settings).
